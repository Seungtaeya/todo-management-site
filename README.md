# 할 일 관리 사이트
로그인 한 사용자가 자신의 할 일을 관리 할 수 있는 미니 웹 서비스 입니다.
할 일 등록, 수정, 삭제 ,상태 변경, 검색 기능을 제공합니다.

개발 기간은 2026.05 ~ 2026.05

# 사용 기술 스택
  - Java
  - Spring Boot
  - Spring Data JPA
  - Thymeleaf
  - MySQL
  - Lombok

# 주요 기능
  - 회원가입, 로그인, 로그아웃
  - 할 일 등록
  - 할 일 목록 조회, 상세 조회, 수정/삭제, 상태 변경
  - 상태 필터
  - 제목 검색, 내용 검색
  - 본인의 할 일만 접근기능
  - 예외 처리 및 에러 메시지 표시

# 예외 처리 내용
  - 중복 아이디 회원가입 예외처리
  - 할 일 필수값 누락 예외 처리
  - 존재하지 않는 Todo 예외 처리
  - 본인 Todo가 아닌 경우 접근 차단
  - 글로벌 예외 처리기로 공통 예외 처리
